20. Movie Mastery
Each movie should have its own progression.

Example:

THE CONJURING

MOVIE MASTERY

████████████████░░░░ 80%

Games Played       4
Best Score         8,200
Best Streak        7
Accuracy           80%

Mastery can initially be calculated using:

mastery =
correct answers / total answers × 100

Clamp the value between 0 and 100.

Later this can become more sophisticated.
