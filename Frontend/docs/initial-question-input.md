Each movie should have at least:

5–10 questions

The prototype does not need hundreds of questions.

Quality and gameplay flow are more important than quantity.

27. Question Distribution
For each movie, create questions across different categories.

Example:

2 × General Trivia
2 × Characters
2 × Plot
2 × Quotes
2 × Difficult / Expert

The Mixed mode should randomly select questions from the available pool.

Do not repeat the same question during a single game.
