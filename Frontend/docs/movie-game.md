1. Project Overview
Build a static, game-oriented movie quiz website using:

HTML5

CSS3

Vanilla JavaScript

Local browser storage via localStorage

No backend

No database

No authentication

No external API dependencies

No frameworks unless absolutely necessary

The prototype should feel like a small arcade-style movie game, not a traditional informational movie website.

The core game loop is:

Genre
  ↓
Movie
  ↓
Quiz Mode
  ↓
Questions
  ↓
Score
  ↓
Results
  ↓
Movie Mastery / High Score

The application should work entirely in the browser.
